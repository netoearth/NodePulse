NodePulse 代理网络测速与出境链路诊断工具，深度对标 speed.cloudflare.com 的设计语言与度量标准，针对中国大陆 GFW 干扰及代理节点特性进行了全面定制：
核心功能与技术实现
40 组高频连发延迟与丢包率点阵（动画显示）
数据包时序点阵：40 组数据包实时连发，探针飞行时带有雷达脉冲光效；接收后按色阶渲染：极速绿色（<80ms）、正常琥珀（80–180ms）、高延迟紫色（>180ms）及超时红色叉号（丢包 / GFW TCP Reset 阻断）。
延迟分布直方图：按 5 个时延区间及丢包桶动态统计柱状占比。
RFC 3550 测量参数：实时计算最低时延（Min）、中位数（Median）、平均值（Mean）、最高值（Max）、网络抖动（Jitter）及丢包率（%）。
GFW 链路健康诊断：自动识别专线（IPLC/IEPL）、晚高峰 QoS 拥塞以及特征阻断。
多阶梯下载与上传吞吐量测速
阶梯式分块下载：实时采样吞吐量（Mbps），记录峰值速率与平均速率。
时序波形图（Bandwidth Waveform）：实时 SVG 动态波形曲面图，直观展现出境带宽的爬升与稳定性。
载荷延迟与缓冲区膨胀（Bufferbloat）：对比空闲 Ping 与满速下载/上传下的延迟膨胀，生成 A+ 至 F 级评分。
全方位公网出口与路由信息（Egress Telemetry）
公网出口 IP：自动识别 IPv4 / IPv6，支持一键复制。
运营商与 ASN：解析 Autonomous System 编号与归属组织（如 AS13335 Cloudflare、AS16509 Amazon、AS45102 等）。
物理归属地与国旗：解析所在国家、城市、地区。
Cloudflare Anycast 接入点（Colo）：自动映射 IATA 航空代码（如 HKG 香港、NRT 东京、SIN 新加坡、SJC 圣何塞等）。
原生住宅 vs 机房 VPS 判定：辨别出口 IP 是否为数据中心托管还是家庭宽带。
DNS 泄漏与防污染检测：排查解析请求是否留在隧道内，防止境内 DNS 投毒。
全球主要路由节点延迟矩阵
覆盖亚太核心与欧美数据中心（香港、东京、新加坡、加州圣何塞、台北、首尔、法兰克福），并内置中国大陆直连探测点（用于诊断代理客户端是否配置了合理的规则分流，防止国内网站反向绕行境外减速）。
支持一键批量全测与单个节点独立重测，并可自定义添加任何目标公网域名或 VPS IP 进行 10 发探针测试。
流媒体与 AI 服务出境解锁探测
检测 OpenAI / ChatGPT、Claude / Anthropic、Netflix、YouTube Premium、Disney+ 及 Google 搜索可用性。
诊断报告一键导出
支持一键导出格式化 Markdown 报告 或结构化 JSON，方便向节点服务商提交工单或在技术社区排错。
